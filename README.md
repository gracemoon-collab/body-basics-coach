# 몸 기본기 코치 (시제품 v0.4)

체형·기능·생활 습관·식사 반응을 함께 살펴 단계별 운동과 지속 가능한 식사 습관을 제안하는 웹앱 시제품입니다.

## v0.4 주요 변경
- 위험 신호를 선택해도 분석을 중단하지 않고 나머지 체형·식사·움직임 결과를 모두 출력
- 위험 신호는 상단 안전 안내와 항목별 답변으로 표시
- 건강 상태를 여러 개 선택하면 한 항목만 남기지 않고 선택한 상태별 회복 답변을 모두 출력
- 불편 부위, 스쿼트 보상, 가동성 제한, 알레르기·제외 음식, 식사 반응을 선택한 항목별로 모두 출력
- 위험 신호가 있는 운동 화면은 이완·가동성 중심의 저강도 결과를 제공
- 회복 우선 이유, 2주 목표, 식습관, 스트레칭·이완, 진료 기준, 회복 체크인 유지

## 결과 원칙
1. 선택한 항목은 삭제하거나 결과를 가리지 않습니다.
2. 위험 신호도 결과를 중단시키지 않고 안전 안내와 함께 출력합니다.
3. 여러 건강 상태가 겹치면 모든 상태의 답변을 차례대로 표시합니다.
4. 개인 기록은 브라우저 localStorage에만 저장합니다.

## 결과 구조
- 위험 신호 안전 안내와 항목별 답변
- 회복 우선 경로 5개
- 일반 체형 유형 11개
- 식사 방향 4개, 운동 단계 S1–S4, 필요 태그 6개, 식사 반응 태그 14개 조합

## 주의
- 진단·처방이 아닌 생활 운동·식사 습관 코칭 시제품입니다.
- 긴급한 증상에는 응급 안내를 표시하지만 사용자가 선택한 분석 결과는 계속 제공합니다.
- 체질 정보는 참고일 뿐 핵심 처방변수로 사용하지 않습니다.
- 영상은 YouTube 링크로만 연결합니다.
