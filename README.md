# 몸 기본기 코치 (시제품 v0.2)

체형·기능·생활 습관·식사 반응을 함께 살펴 단계별 운동과 지속 가능한 식사 습관을 제안하는 웹앱 시제품입니다.

## v0.2 주요 변경
- 만 19세 이상 성인용 열량·단백질 계산
- 현재·목표 체중, 활동량, 체지방·근육 조합을 반영한 체형 유형
- 식사 반응 특성별 일반 조절과 의료 확인 신호
- 사상체질 참고 체크와 8체질 진단 이력 참고
- 공공기관·병원·물리치료사·대표 홈트 채널 운동 영상 100편
- 임신·수유, 섭식장애 위험, 신장질환, 혈당강하제 사용 보호모드
- 위험 신호 즉시 차단, 영상 금기 공통 필터, 주간 체크인 중복 방지

## 주의
- 진단·처방이 아닌 생활 운동·식사 습관 코칭 시제품입니다.
- 체질 정보는 참고일 뿐 핵심 처방변수로 사용하지 않습니다.
- 개인 기록은 서버로 전송되지 않고 브라우저 localStorage에만 저장됩니다.
- 영상은 YouTube 링크로만 연결합니다.
