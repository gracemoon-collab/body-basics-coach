# 몸 기본기 코치 (시제품 v0.3)

체형·기능·생활 습관·식사 반응을 함께 살펴 단계별 운동과 지속 가능한 식사 습관을 제안하는 웹앱 시제품입니다.

## v0.3 주요 변경
- 보호모드를 단순 숫자 숨김에서 실제 회복 계획으로 전면 수정
- 회복 우선 이유 → 2주 습관 목표 → 식습관 변화 → 스트레칭·이완 → 진료 기준 순으로 안내
- 섭식 부담, 임신·수유, 신장 질환, 혈당강하제·인슐린 사용의 4가지 회복 경로
- 보호모드 전용 주간 체크인과 같은 주 중복 저장 방지
- 보호모드에서는 체형·열량·단백질·감량 목표를 노출하지 않고 S1 회복 단계로 시작
- 임신·수유 중에는 일반 스트레칭 영상을 자동 추천하지 않음

## 결과 구조
- 위험 신호 중단 경로 1개
- 회복 우선 경로 4개
- 일반 경로 체형 유형 11개
- 일반 경로는 식사 방향 4개, 운동 단계 S1–S4, 필요 태그 6개, 식사 반응 태그 14개를 조합

## 주의
- 진단·처방이 아닌 생활 운동·식사 습관 코칭 시제품입니다.
- 체질 정보는 참고일 뿐 핵심 처방변수로 사용하지 않습니다.
- 개인 기록은 서버로 전송되지 않고 브라우저 localStorage에만 저장됩니다.
- 영상은 YouTube 링크로만 연결합니다.
